\doxysubsection{Detailed Description}
Сущность, представляющая услугу автомойки. 

Этот класс отображается на таблицу {\ttfamily services} в базе данных и содержит информацию об услугах, предоставляемых автомойками. Каждая услуга имеет название и дополнительное описание.

{\bfseries{Примечание\+:}} Класс назван {\ttfamily ServiceC} во избежание конфликта с зарезервированным словом "{}service"{} в некоторых контекстах.
