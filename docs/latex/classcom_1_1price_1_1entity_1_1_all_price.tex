\doxysubsection{Detailed Description}
Сущность, представляющая ценовую информацию для услуг автомойки. 

Этот класс отображается на представление {\ttfamily allprice} в базе данных и содержит информацию о ценах, сроках выполнения услуг и дополнительных деталях. Использует составной первичный ключ {\ttfamily \doxylink{classcom_1_1price_1_1entity_1_1_all_price_id}{All\+Price\+Id}}.
