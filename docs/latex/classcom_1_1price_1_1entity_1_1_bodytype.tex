\doxysubsection{Detailed Description}
Сущность, представляющая тип кузова автомобиля. 

Этот класс отображается на таблицу {\ttfamily bodytypes} в базе данных и хранит информацию о различных типах кузовов автомобилей (например, седан, внедорожник, универсал). Используется для классификации услуг автомойки в зависимости от типа кузова.
