\doxysubsection{Detailed Description}
Контроллер для управления всеми ценами на услуги автомоек. 

Обрабатывает HTTP-\/запросы, связанные с операциями CRUD для агрегированных данных о ценах. Работает с составными идентификаторами в строковом формате и предоставляет веб-\/интерфейс для создания, просмотра, обновления и удаления записей о ценах.

{\bfseries{Особенности\+:}} 
\begin{DoxyItemize}
\item Использует составные идентификаторы ({\ttfamily \doxylink{classcom_1_1price_1_1entity_1_1_all_price_id}{All\+Price\+Id}}) в формате строки 
\item Отображает только актуальные цены (последние для каждой комбинации) 
\item Поддерживает сложное обновление с изменением составного ключа 
\item Обрабатывает строковые представления идентификаторов через {\ttfamily \doxylink{classcom_1_1price_1_1entity_1_1_all_price_id_a853b99801be67962d41b6aae4a1852a7}{All\+Price\+Id\#from\+String(\+String)}} 
\end{DoxyItemize}
