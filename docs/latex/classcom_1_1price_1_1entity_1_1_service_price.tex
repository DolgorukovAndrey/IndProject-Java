\doxysubsection{Detailed Description}
Сущность, представляющая цену на услугу автомойки. 

Этот класс отображается на таблицу {\ttfamily servicesprice} в базе данных и содержит информацию о стоимости услуги для конкретной автомойки, типа кузова и даты. Обеспечивает уникальность комбинации услуги, автомойки, типа кузова и даты через ограничение уникальности базы данных.

{\bfseries{Бизнес-\/правила\+:}} 
\begin{DoxyItemize}
\item Для одной и той же услуги, автомойки и типа кузова не может быть двух цен на одну дату 
\item Время выполнения услуги должно быть от 1 до 600 минут 
\item Стоимость услуги должна быть от 0 до 1,000,000 рублей 
\end{DoxyItemize}
